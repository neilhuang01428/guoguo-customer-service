Procreate 筆刷怎麼調成
自己要的手感？

Brush Studio 有 14 個分頁、上百個滑桿，但你不用背——先懂一件事，剩下的幾乎都推得出來。

想把 Procreate 筆刷調成自己要的手感，先記住一句話就好：一筆線其實是「同一個形狀沿著你的路徑蓋很多次章」。這不是比喻，是官方對 Stroke Path 的定義原文——懂了它，那十幾頁滑桿就從「要背」變成「推得出來」。

心法一 · 懂了那句話，這些滑桿一起解鎖
間距、抖動、散佈、數量——這幾頁管的都是同一件事：那些印章怎麼排。所以它們不是四個要分開背的知識，是同一個概念的四個面向。
心法二 · 看不懂的滑桿？官方教你這招
把 Stroke Path 的 Spacing 拉高，一筆會散成一顆顆分開的印章，那個設定在動什麼就看得見了。官方還補一句：之後把間距調回正常，這個畫面也會一直幫你想像。

core_concepts

00 · 先懂三個概念，其他都好講

Brush Studio 第一次打開真的很嚇人。但那十幾頁不是十幾個獨立知識——它們全部圍著三件事轉。

🔨
一、一筆 ＝ 沿著路徑蓋很多次章官方原文寫得很白：Procreate 是「沿著你手指或 Apple Pencil 移動的路徑，畫上很多個點」來組成一筆。所以「線」不是連續的，是密集的印章疊出來的錯覺。
🫙
二、Shape 是容器，Grain 是紋理Shape 管印章的「輪廓長什麼樣」（圓的、扁的、葉子形的），Grain 管印章「表面的質感」（粗糙的紙、噴點、布紋）。兩個完全獨立，可以自由組合。
🧻
三、Grain 像油漆滾筒滾筒鎖住不轉，花紋會被拖成一道；滾筒放開會轉，花紋就一段一段印上去。Procreate 把這兩種行為叫 Moving 和 Texturized，第 02 節有圖。
官方自己教的偵錯神技，學會這招就能自學
手冊裡有一段 Pro Tip：想看清楚某個設定在做什麼，就去 Stroke Path 把 Spacing 滑桿往上拉，筆畫會從「糊在一起的一條線」變成「一顆顆看得見的印章」。
官方還加了一句很體貼的話：就算你之後把間距調回正常，這個畫面也會一直幫你想像每個設定在做什麼。本篇大部分的圖，就是照這個邏輯畫的。

先認識版面：其實只有三塊

動手前先做這件事，才不會回不去
Brush Studio 裡有一個 Reset Point（還原點）：調到一個滿意的狀態時存一個，之後亂調壞了可以跳回來。但官方明講每支筆刷同時只能有一個還原點。
所以更保險的做法是：先複製一支筆刷再改。原廠筆刷改壞了很難救，複製品壞了刪掉就好。
stroke_path

01 · 一筆是怎麼組成的（Stroke Path）

這一頁是整個 Brush Studio 的地基，也是最該先玩的一頁。它管的就是「那些印章怎麼排列」。

Spacing（間距）：把線拆回印章

官方對 Spacing 的定義是「設定你的筆刷形狀沿著路徑蓋幾次章」。直接看圖最快：

Spacing 低
間距小，印章疊在一起、看起來就是一條連續的線。日常用的筆刷都長這樣。
Spacing 中
間距拉大，印章開始分家，你看得到一顆一顆的形狀了。
Spacing 高
間距很大，變成一串分開的圖章——做虛線、腳印、鏈條就是靠這個。

同一支筆刷、只動 Spacing。看得到印章分開的那一刻，你就懂什麼叫「一筆是蓋很多次章」了。

一個看起來像 bug、其實不是的行為
就算你把 Spacing 拉到 0%，加上高一點的 Spacing Jitter，還是會看到間距在變。官方解釋過：間距有一個最小值，不會真的變成零。看到這個不用懷疑筆刷壞了。

Jitter（抖動）：讓排列不要太整齊

印章排太整齊會很像電腦畫的。Jitter 就是拿來加一點亂度的，而且分成兩個方向：

原始
沒有抖動。印章乖乖排在你畫的那條線上。
Jitter Lateral
Lateral（垂直向）：印章往線的兩側散開，線變毛毛的。
Jitter Linear
Linear（沿線向）：印章沿著前後方向亂跑，間距變得不規則。

兩種抖動的方向不一樣：一個讓線變寬變毛，一個讓疏密變亂。

Fall Off（衰減）：這一筆能撐多長

Fall Off 關
關掉。整條線從頭到尾一樣濃。
Fall Off 中
中等。畫到後面慢慢變淡，像顏料快用完。
Fall Off 高
拉高。很快就淡到看不見，適合做飛白、噴霧感。

Fall Off 管的是「這一筆能撐多長」，跟壓力無關——你用力再重也救不回已經淡掉的尾巴。

02 · 形狀與紋理：容器和它的表面

知道一筆是印章排出來的之後，下一個問題自然就是——那顆印章長什麼樣？答案分兩層：Shape 管輪廓，Grain 管表面。

Rotation：形狀要不要跟著筆畫轉

-100% 反向
−100%：形狀跟筆畫反方向轉，做出扭轉、麻花的效果。
0% 不動
0%：形狀方向固定不動，不管你往哪畫都是同一個角度——扁頭筆、書法筆就是這樣。
100% 跟隨
100%：形狀跟著筆畫方向轉，像一支永遠對齊行進方向的刷子。

「橫粗直細」的書法感，關鍵就在中間這格：把形狀壓扁、再把 Rotation 設成 0%。

Scatter 與 Count：讓一筆變成「一撮」

原始
原始：每個點蓋一次，方向一致。
Scatter
Scatter：每個印章隨機轉一個角度，看起來自然多了。
Count 5 + Scatter
Count 5 ＋ Scatter：每個點蓋五次、每次方向不同——一筆下去就是一撮。

草叢、樹葉、噴濺都是這樣做出來的。Count 官方上限是 16 次。

Count Jitter 的官方算式，順手記一下
Count 設 10、Jitter 設 0%，就是每個點都固定蓋 10 次。Jitter 拉到 100%，每個點會在 1～10 次之間隨機。拉 50% 就是在 5～10 之間隨機。
想做「有疏有密的草叢」，動這一格比動 Scatter 更有效。

Grain：滾筒鎖住還是放開

這是整個 Brush Studio 裡最容易搞混、但一講就懂的分岔。用滾筒油漆來想最快：

Moving（滾筒鎖住）
滾筒鎖住：紋理被筆畫拖著走，會拉出條紋、會糊開。官方說它「行為比較像傳統畫布上的顏料」。
Texturized（滾筒放開）
滾筒放開：紋理像蓋印章一樣固定在畫布上，不拖不糊，邊緣乾淨。

想像牆上滾油漆：滾筒不轉就是拖出一道，滾筒會轉就是把花紋一段段印上去。

為什麼你的 Grain 設定有一半是灰的
Grain 頁有好幾個設定只在 Moving 模式下才會出現（縮放、旋轉、深度最小值、深度抖動、位移抖動）。切到 Texturized 它們就消失了。
不是你的 App 壞掉，是這些設定在「紋理不會動」的模式下本來就沒有意義。
要做「圖樣筆刷」的話，記得關掉這一個
如果你想做的是能接續、不會斷掉的圖樣（官方舉的例子是格線筆刷），一定要把 Offset Jitter 關掉。它會讓每一筆的紋理起點隨機位移——對草叢很好用，對格線就是災難，接縫永遠對不起來。

03 · 調出「手感」：收筆、穩定、速度

到這裡形狀已經對了，但可能還是覺得「畫起來不像真的筆」。手感通常來自這三頁。

Taper（收筆錐化）：筆鋒從哪來

Taper 關
關掉。起筆收筆都是方頭，像麥克筆。
兩端 Taper
兩端都收尖，像毛筆或鋼筆的筆鋒。
只有收筆
只收尾端：起筆保持飽滿、收筆才收掉。

Taper 是「筆畫兩端」的形狀，跟你壓多重無關——它是筆刷自己的個性。

Stabilization（穩定器）：手抖救星，但有兩種個性

原始手抖
沒有穩定。手抖多少，線上就看得到多少。
StreamLine
StreamLine：把線往「你大概想畫的那條」拉順，適合描線、寫書法。
Motion Filtering
Motion Filtering：直接把小抖動剔掉，線條變得比較硬、比較有稜角。

兩種穩定的個性不同：一個是拉順，一個是剔掉。描線用前者，畫幾何用後者。

Dynamics（速度）：畫快畫慢會不會不一樣

Speed Size −100%
Size −100%：畫慢的線比較細、畫快的線比較粗。
Speed Size 0%
Size 0%：粗細完全不受速度影響。
Speed Size +100%
Size +100%：反過來，畫越快線越細——最像真實的筆。

注意這一頁官方明講不吃壓力也不吃傾斜，它只看你畫多快。用手指畫的人靠它做出變化。

這一頁跟壓力完全無關，官方明說的
Dynamics 整頁的官方說明裡有一句：這些設定不依賴 Apple Pencil 的壓力與傾斜。它只看你畫多快、以及隨機值。
所以有兩個實用推論：一、用手指畫畫的人靠這一頁做出變化；二、如果某支筆刷「感覺沒有感壓」，先看看它的變化是不是其實來自 Dynamics——那是規格，不是故障。
paint

04 · 顏料的行為：濕度、顏色、算圖

前面三節都在講「形狀」。這一節開始講「顏料」——為什麼水彩會暈開、為什麼粉筆的顏色會花花的。

Wet Mix（濕混）：筆上有多少顏料、摻了多少水

Charge 高
Charge 高：筆上顏料很多，一路畫都很濃。
Charge 低
Charge 低：畫著畫著顏料就用完，尾巴自然變淡。抬筆再下筆等於重新沾一次顏料。
Dilution 高
Dilution 高：水多顏料少，顏色透、邊緣會暈開。

這一頁在模擬「筆上有多少顏料、摻了多少水」——水彩、油畫的味道就是從這裡來的。

一個很真實的細節：抬筆等於重新沾顏料
Charge 設低的時候，畫著畫著顏色就會用完。這時候把筆抬起來、再放下去畫，等於重新沾了一次調色盤——顏色又回來了。
Dilution（稀釋）拉高時這個行為最明顯，也最像真的在畫水彩。

Color Dynamics（色彩動態）：讓顏色自己有變化

Jitter 關
關掉。整筆都是你選的那個顏色。
Hue Jitter 低
Hue Jitter 低：顏色只有輕微飄移，看起來像手繪的自然不均勻。
Hue Jitter 高
Hue Jitter 高：整筆跳過整個色譜，做彩虹、粉筆、噴漆很好用。

想要「看起來不像電腦畫的」，這一頁比什麼都有效——一點點就夠了。

Rendering（算圖）：顏色怎麼疊上去

這一頁不確定就別亂動
Rendering 決定的是「顏色疊加時怎麼運算」，它的差異很微妙、但一改就會影響整支筆刷的個性，而且越右邊越吃效能。
建議的做法是：先把其他頁都調好，最後才回來試 Rendering，一次換一個模式、在塗鴉板上畫兩筆比較。
your_pencil

05 · 接上你的筆：哪些設定你手上這支做得到

Brush Studio 有一整頁叫 Apple Pencil，管的是「你的筆怎麼影響這支筆刷」。但這裡有個很多教學不會講的前提——有些設定要特定世代的筆才會有作用。

先看傾斜：有一段角度是完全無效的

「我的傾斜設定沒反應」，九成是這個原因
官方寫得很清楚：0～15 度時筆尖根本還沒碰到畫布，綁在這個範圍的設定不會有任何效果；16～30 度「可能不準」；30～90 度才是官方建議的使用範圍。
所以調傾斜筆刷時，觸發點設在 30 度以上才有意義。這也剛好對應真人握筆的角度。

果果視角：哪一代筆、哪一台 iPad 才有這些功能

我們手上 2018 到 2026 年的 iPad 與各代 Apple Pencil 都在架上，所以很清楚一件事：教學影片裡看到的設定，你手上那支筆不一定做得出來。買二手機或平價筆之前，這張表值得先看一眼。

Brush Studio 裡的設定需要什麼才有作用沒有的話會怎樣
Pressure（壓力）第 1 代、第 2 代、Apple Pencil ProUSB-C 版沒有壓力感應，粗細不會跟著手勁變
Tilt（傾斜）原廠 Apple Pencil 各代都有多數平價副廠筆做不到，側鋒效果出不來
Input style · Azimuth（方位角）能回報方位角的筆形狀不會跟著你握筆的方向轉
Input style · Barrel roll（轉筆桿）只有 Apple Pencil Pro其他款完全沒有這個選項
Hover（懸浮預覽）要機器與筆都支援懸浮筆還沒碰到螢幕時不會顯示預覽
誠實說：懸浮這一列請以官方比較表為準
懸浮支援與否同時看 iPad 機型和 Pencil 世代，組合很多，而且會隨新機型變動。我們不在這裡列機型清單，是因為那種表最容易過期、過期又最容易害人買錯。
要確認就去 Apple 官網的 Apple Pencil 機型比較表對一次，那是唯一會跟著更新的來源。
還有一個游標設定，設了常常「沒反應」
Brush Studio 裡可以設定筆刷游標的外框樣式，但官方註明一個前提：要先把「Actions → Prefs → Advanced cursor」設成 Per Brush，否則全域設定會蓋過去，你在筆刷裡設的東西根本不會顯示。
這跟壓力曲線是同一種結構——全域壓過單支筆刷。在 Procreate 裡看到「設了沒反應」，先想想是不是有一層全域設定在上面。

06 · 六道食譜：想要這種效果，該動哪幾頁

概念講完了，來收成可以直接動手的東西。下面六道是最常見的需求，各自對應哪幾頁：

你想做出主要動這幾頁關鍵動作
石墨鉛筆立起來畫細線、斜著打陰影Shape ＋ Grain ＋ Apple Pencil紋理選粗糙的、把傾斜接到 Size，觸發點設 30 度以上
書法／扁頭筆橫粗直細Shape形狀壓扁，Rotation 設 0%（形狀不跟著筆畫轉）
水彩會暈開、顏料會用完Wet Mix ＋ GrainDilution 拉高、Charge 壓低，Grain 用 Moving
草叢／樹葉／噴濺一撮一撮Shape ＋ Stroke PathCount 調高、開 Scatter、Spacing 拉大
像素畫硬邊、不糊Shape ＋ Rendering形狀用方的、關掉平滑相關的柔化
自己拍的照片當紋理Grain用 Grain 編輯器匯入圖片；做圖樣要關掉 Offset Jitter
這張表為什麼沒有數字？因為官方也沒給
網路上很多筆刷教學會給你「Spacing 設 12%、Jitter 設 34%」這種配方。老實說，Procreate 官方從來沒有公布過任何一組配方數值——上面這些方向是依官方對各設定的說明推出來的，方向可靠，數字得你自己在塗鴉板上試。
而且同一組數字換一個 Shape 就不成立了。與其抄數字，不如記住「這個效果歸哪一頁管」，那個知識才帶得走。
pitfalls

07 · 雷區，以及怎麼還原

調筆刷最怕的不是調不出來，是回不去。這節把幾個真的會卡住人的地方講完。

  • 直接改原廠筆刷——原廠筆刷改壞了很難完美還原。動手前先複製一支，改複製品。
  • 以為還原點可以存很多個——官方明講每支筆刷同時只能有一個還原點，存新的就蓋掉舊的。
  • 想在 Brush Studio 裡改筆刷名稱——自 Procreate 5.4 起這裡改不了了，要回筆刷庫長按筆刷選「重新命名」。
  • 照抄別人的數值卻沒換 Shape——同一組數字配不同形狀，結果會差很多，抄了通常不像。
  • 放大到底還是很細——去 Properties 看看，那裡可以幫側邊欄的尺寸／不透明度滑桿設上下限，設過就會被夾住。

兩個 Reset，管的範圍不一樣

Reset all Brush Settings
在 Brush Studio 裡，把目前這一支筆刷的設定還原。官方明白註明它只作用於當前筆刷，不會動到你其他筆刷。
Reset Point（還原點）
你自己存的存檔點，跳回存檔當下的狀態。適合「我想再試試看，但想留一條退路」的時候。
一個不用打開設定就能判斷筆刷的小技巧

筆刷庫裡每支筆刷旁邊那條預覽線，官方說明它是「一筆由左到右、壓力逐漸增加、最後再放掉」的示範筆畫，而且任何綁在壓力上的效果都會在預覽裡被示範出來。所以那條預覽線如果從頭到尾一樣粗，這支筆刷多半沒有把壓力接到粗細上。

兩個但書：一、Properties 裡有個「Use Stamp Preview」開關，打開之後預覽會變成單一印章而不是筆畫，那就看不出來了；二、「預覽沒變化 → 一定沒接壓力」是我們從官方那句話反推的，官方並沒有直接這樣說。當快篩用可以，別當結論。

evidence

08 · 這篇哪些是官方說的、哪些是推論

筆刷設定這種題目，網路上很多說法查不到出處。我們把每一條的等級標出來，你可以自己決定要信到什麼程度。

說法等級依據
Brush Studio 共 14 個可調分頁已確認官方手冊該頁開頭逐字：「探索 Procreate 筆刷的 14 個可調整屬性」
一筆是「沿路徑蓋很多次章」組成的已確認官方對 Stroke Path 的定義原文；Spacing 的說明也直接用了「蓋章」這個詞
拉高 Spacing 可以看清楚每個設定在做什麼已確認官方手冊的 Pro Tip 原文，含「之後調回正常也會幫你想像」那句
Spacing 設 0% 仍看得到間距變化已確認官方說明間距有一個最小值
Count 上限 16、Jitter 100% 時在 1～最大值之間隨機已確認官方對 Count 與 Count Jitter 的逐字說明
Dynamics 整頁不依賴壓力與傾斜已確認官方逐字，並說明用手指畫的人可用這頁做出變化
傾斜 0～15 度無效、30～90 度才是建議範圍已確認官方對 Tilt 的逐字說明
游標外框要先把 Advanced cursor 設成 Per Brush已確認官方註明否則會被全域設定覆蓋、不會顯示
Barrel roll 只有 Apple Pencil Pro 有已確認官方 Input style 三個選項的逐字說明
還原點每支筆刷只能有一個、5.4 起不能在此改名已確認官方對 Reset Point 與 Brush Title 的逐字說明
六道食譜該動哪幾頁合理推論方向依官方對各設定的描述推出，但官方沒有給過任何配方的具體數值，數字要自己試
預覽線沒有粗細變化 → 這支筆刷沒接壓力合理推論官方只說「綁在壓力上的效果會在預覽裡被示範」，反過來推是我們的判斷，當快篩用
為什麼要特別標出「沒有數字」這件事
因為那正是這個主題最容易誤導人的地方。你在別處看到有人給你一組精確到個位數的筆刷配方時，可以回頭問一句：這組數字配的是哪一個 Shape？
換一個形狀，同一組數字就不成立了。我們寧可教你哪一頁管什麼，也不想給你一組換個筆刷就失效的數字。
